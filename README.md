===========================================================
                    NOVA AI CHATBOT
===========================================================

Project Name:
-------------
Nova AI Chatbot

Description:
------------
Nova AI is an AI-powered chatbot developed using FastAPI,
PostgreSQL, HTML, CSS, JavaScript, and the Hugging Face
Transformers library. It provides user authentication,
conversation history, AI-generated responses, and a clean
chat interface.

===========================================================
TECHNOLOGIES USED
===========================================================

Backend:
- Python 3.x
- FastAPI
- Uvicorn
- Transformers
- PyTorch
- psycopg2

Frontend:
- HTML5
- CSS3
- JavaScript

Database:
- PostgreSQL

AI Model:
- Qwen 2.5
- Hugging Face Transformers

===========================================================
HOW TO RUN
===========================================================

1. Open Terminal

2. Activate Virtual Environment

Windows:

venv\Scripts\activate

3. Run FastAPI

python -m uvicorn api:app --reload

4. Open Browser

http://127.0.0.1:8000

===========================================================
NOTES
===========================================================

• FastAPI serves both the frontend and backend.
• PostgreSQL stores users, conversations, and chats.
• Hugging Face Transformers is used to load the Qwen 2.5 model.
• Chat history is stored in PostgreSQL.
• Swagger documentation is automatically generated by FastAPI.
